## 3. 不可用档位：不展示（硬规则）

- 前端**只渲染 `available=true` 的档位**；
- 不得渲染 `disabled` 按钮、不得出现"数据积累中/数据不足"占位、不得保留空档位；
- 若某标的某档不可用，该标的的选择器里就不出现这个档；
- 全站文案中不得出现"即将开放/积累中"类档位提示（与 us-110 的旧置灰态一并移除）。

> 迁移说明：需删除 us-110 遗留的 `6m/12m` 置灰态与 `reason` 文案；AC-8 强制检查。

## 4. 样本门槛（2w/4w 必须披露）

2w 只有约 10 个交易日，串行单仓下平仓笔数常为 0~2 笔，**不能当统计结论用**。

| 规则 | 定义 |
|------|------|
| 单标的可展示门槛 | 该档平仓笔数 ≥ 1；0 笔则该档对该标的不展示 |
| 小样本披露 | 笔数 < 3：胜率区显示 `样本不足（N 笔）`，**不显示胜率百分比**；收益率/最大回撤照常显示，但附 `区间极短，波动噪声大` |
| 档位整体门槛 | 池内 ≥ 50%（≥ 30/59）标的该档有 ≥ 1 笔，否则**整档不展示**（不出现按钮） |
| 大样本 | 笔数 ≥ 3 才显示胜率百分比，并始终显示 `M/N` |

## 5. 数据门禁 G-2（长档，11/05 中午）

必须存在书面核查结论（写入 `02_eng.md` 或数据线报告），含：

| # | 核查项 | 通过标准 |
|---|--------|---------|
| G-2.1 | 逐标的覆盖天数 | 池内 `6m` 达标 ≥ 50/59、`9m` ≥ 50/59、`12m` ≥ 50/59 |
| G-2.2 | 日期连续性 | 交易日 0 缺档；非交易日假快照 0 个计入窗口 |
| G-2.3 | 复权同源 | 底座与 archive 同一复权口径（禁止 qfq 与比率混拼）；拼接处异常断层 0 只（或异常标的已剔除并记录） |

- 三项全过 → `6m/9m/12m` 与 `2w/4w` 一同上线；
- 任一项不过 → 三个长档**完全不出现**，只交付 `2w/4w`（+ 既有 `3m`）；
- 不得"先上 6m 再说"或"用 3m 数据冒充 6m"。

## 6. 数据与体积

- `2w/4w` 复用 archive，不新增历史底座，产物增量可忽略（摘要字段数与档位无关）；
- 长档需底座：raw ≤ 315KB / gzip ≤ 130KB，入库为仓库内静态文件，**不依赖本地 95MB 缓存**；
- 产物体积：索引 ≤ 150KB、单摘要 ≤ 20KB；构建 ≤ 5s；Actions 兼容、不新增任务类型；
- 不新增数据库/常驻服务/第三方数据源。
