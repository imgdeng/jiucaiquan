# us-115 · 回测可解释性（逻辑 + 逐笔 + 权益曲线）— 需求文档

> 负责人：产品马 | 日期：2026-11-04 | 阶段：需求 | 优先级：P2 | 迭代：26.11.2

---

## 0. 本卡定了什么

补 3 个模块：**规则说明（静态）→ 逐笔交易（按需加载）→ 累计权益曲线（SVG）**。
不做图表库、不做导出、不做多标的对比；首屏加载不变。

---

## 1. 用户故事

> 作为看到"胜率 52%、收益 8.4%、回撤 12%"的用户，我希望知道这几笔交易具体发生在哪天、为什么平仓、资金曲线在哪一段跌得最多，以便判断这个结果是否可信。

---

## 2. 现状与缺口

| 现状 | 缺口 |
|------|------|
| 摘要 3 数字 + 两行规则 | 无法解释胜率来源、无法感知回撤发生时间 |
| 无逐笔数据产物 | 无法核对"是不是每笔都按规则成交" |
| 无权益曲线 | 无法判断收益是否集中在某一笔 |

---

## 3. 需求细则

### FR-1 逻辑说明（静态，首屏可见）

固定 4 步，顺序不得调整：

1. **信号日 D**：用 D 的 OHLC 计算 `base=(2C+H+L)/4`、`低吸=base-(H-L)`、`高抛=base+(H-L)`；
2. **D+1 触价买入**：若 D+1 最低价 ≤ 低吸价，以低吸价成交；未触及则该信号作废，不计笔数；
3. **卖出**：买入当日或之后最高价 ≥ 高抛价则卖出；持有满 5 个交易日仍未触发，按第 5 日收盘价平仓；
4. **串行单仓**：同一时间最多 1 笔，平仓后才接受新信号；每笔名义投入 1 万元、等额、不复利。

必须附口径说明：`前复权`、`未计佣金、滑点与冲击成本`、`区间与样本交易日数`。

- 不得出现"建议买入/可买入"等祈使句；
- 可使用一张静态 SVG 流程图（4 个节点 + 箭头），不做交互。

### FR-2 逐笔交易（按需加载）

表格字段固定 7 项：

| 字段 | 说明 |
|------|------|
| 买入日 | `YYYY-MM-DD` |
| 买入价 | 保留 2 位小数 |
| 卖出日 | `YYYY-MM-DD` |
| 卖出价 | 保留 2 位小数 |
| 持有天数 | 交易日数 |
| 单笔收益率 | `卖出/买入-1`，保留 2 位小数 |
| 平仓原因 | `高抛` / `到期平仓` |

- 行数必须等于摘要的 `trades`；
- 按买入日升序；
- 393px 下表格转卡片列表（每卡 7 字段），不得横向溢出。

### FR-3 累计权益曲线

- 纵轴：权益指数（起点 100），按交易日；
- 权益 = 初始 100 + 已实现盈亏 + 当日持仓浮动盈亏（与 §4.2 口径一致）；
- 标注：峰值点、最大回撤区间（起止日期 + 回撤幅度）；
- 用内联 SVG 折线，无第三方图表库；
- 图上标注的"最大回撤"必须与摘要值一致（误差 ≤ 0.01pp）；
- 曲线旁必须展示"历史表现不代表未来收益"。

### FR-4 数据产物

- 新增 `data/backtest/detail/{code}.json`，字段：
  `code, window, start, end, trades[], equity[], maxDrawdownRange`;
- 单标的单档 ≤ 6KB raw；59 只 × 3 档总量 ≤ 800KB raw（明细不进首屏、不进索引）；
- 页面点击"查看逐笔与曲线"后才 fetch，同一标的同一档缓存复用；
- 首屏与切档请求路径不得包含 detail 文件。

### FR-5 边界

- 区间末仍未平仓的交易：标注"区间末未平仓，按第 5 日收盘计"，**不得**展示为"当前持仓""当前买点"；
- 无交易（0 笔）：逐笔区显示"该区间未触发交易"，曲线显示水平线（100），不伪造波动；
- 样本不足（< 3 笔）：照常展示，但顶部标注"样本不足（N 笔）"。

## 5. 非目标

- ❌ 图表库、缩放/拖拽/悬浮 tooltip；
- ❌ 多标的曲线对比、组合回测；
- ❌ CSV/图片导出、分享海报；
- ❌ 未平仓头寸作为"当前持仓"展示；
- ❌ 实时更新/盘中信号。

---

## 6. 风险

| 风险 | 应对 |
|------|------|
| 明细被误读为"当前可买点" | 只展示历史已平仓交易；未平仓明确标注"区间末未平仓" |
| 权益口径与摘要不一致 | 明细与摘要同源生成（同一构建脚本同一函数），AC-3 强校验 |
| 体积失控 | 明细独立文件 + 按需加载；总量 ≤ 800KB |
| 首屏变慢 | 首屏零明细请求；AC-4 机械检查 Network |
| 表格在 393px 溢出 | 卡片列表，AC-8 实测 |

---

## 7. 合规

- 只展示历史成交记录，不展示"下一买点/当前信号"；
- 每条明细保留区间、样本数、未计费用说明；
- 不出现收益承诺、不出现"胜率这么高值得买"类结论；
- 曲线旁固定"历史表现不代表未来收益"。
