## 3. 形态 A：中性分布 / 概览（默认开发范围）

### FR-A1 指标

概览卡固定展示 4 项 + 样本数：

| 指标 | 定义 |
|------|------|
| 正收益只数 | 区间累计收益率 > 0 的标的数 / 样本标的数 |
| 收益中位数 | 池内各标的区间累计收益率的中位数 |
| 胜率中位数 | 池内各标的胜率的中位数 |
| 回撤中位数 | 池内各标的最大回撤的中位数 |
| 样本数 | 参与统计的标的数（必须显示，如 59 只） |

### FR-A2 可选分档分布

- 分档固定为 `<0%`、`0~20%`、`20~50%`、`>50%` 四档；
- 展示各档标的数（不展示标的名称/代码）；
- 用横向条形图即可，不引入图表库。

### FR-A3 文案

- 标题：`回测结果概览`
- 必须含：`以下为池内标的回测统计分布，非标的推荐` + `历史表现不代表未来收益` + `区间：{start} ~ {end}（{n} 个交易日）` + `未计佣金与滑点`；
- 不得出现 `TOP / 排行 / 最佳 / 最强 / 值得买 / 热门`。

### FR-A4 数据

- 聚合结果写入预计算 JSON（索引内新增聚合字段，约 1KB）；
- 页面不新增请求类型、不做端上计算。

## 4. 形态 B：按收益排序一览（备选，G-1 通过后才定义完整 AC）

若用户拍板 B，至少必须满足：

| 编号 | 约束 |
|------|------|
| B-1 | 标题固定为"历史回测收益率排序（非推荐）"，不得用"TOP/榜/最佳" |
| B-2 | 每行必须展示：代码、名称、区间收益率、胜率、笔数、区间 |
| B-3 | 入榜门槛：该标的该档位平仓笔数 ≥ 5；不足者不入榜 |
| B-4 | 默认排序为代码或成交额；收益排序必须是用户**主动点击**后生效，不默认呈现 |
| B-5 | 不得上首页、不得推送、不得生成分享海报 |
| B-6 | 每行及板块页脚均展示"排序仅反映历史统计，不构成投资建议，不代表未来收益" |
| B-7 | 合规复核：产品马 + 项目马双签，出现 `推荐/热门/最佳/最强` 任一即不通过 |
