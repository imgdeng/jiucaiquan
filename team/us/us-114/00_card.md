## 一句话描述

满足"想看看哪些标的回测收益高"的好奇，但必须先决定：只给**中性分布**，还是给**按收益排序的一览**。

## 背景

用户反馈：能不能找出"回测收益率 TOP"并展示，"读者会好奇"。

这是本批 6 条里**唯一直接触碰荐股红线**的需求。按 [compliance.md](file:///Users/gdeng/work/jiucaiquan/docs/compliance.md)：

- 允许：历史数据研究、回测和复盘；
- 避免：荐股、带单、牛股、保证收益、付费买卖信号；
- 一份"按历史收益排序"的清单，天然会被读者当作"买入候选"，即使加免责声明，暗示仍然存在。

## 合规评估：两种形态

### 形态 A：中性分布 / 概览（不点名排序）

| 项 | 内容 |
|----|------|
| 形态 | 展示 59 只标的的**统计分布**：正收益只数、收益中位数、胜率中位数、最大回撤中位数；可选一个分档直方图（`<0%` / `0~20%` / `20~50%` / `>50%`） |
| 是否点名标的 | **否**（不出现任何代码/名称） |
| 荐股暗示风险 | **低**：没有"买这个"的指向 |
| 必需文案 | "以下为池内标的回测结果分布，不是标的推荐；历史表现不代表未来收益；区间/规则/样本数见下" |
| 工时估算 | 4h（产物 + 前端统计卡 + 直方图） |
| 体积增量 | 约 1KB（索引内聚合字段） |
| 建议 | **优先考虑**，可进 26.11.2 |

### 形态 B：按收益排序一览（点名 Top N）

| 项 | 内容 |
|----|------|
| 形态 | Top 10 表格：代码/名称/区间收益率/胜率/笔数；可按收益或胜率排序 |
| 是否点名标的 | **是** |
| 荐股暗示风险 | **高**：榜单会被当作买入清单；小样本标的可能偶然居前（3m 档尤其明显）；"TOP"本身即推荐语义 |
| 必需文案 | 标题必须为"历史回测收益率排序（非推荐）"；每行展示区间与笔数；入榜门槛 ≥ 5 笔；附"排序仅反映历史统计，不构成投资建议，不代表未来收益"；不得出现"最佳/最强/值得买/热门" |
| 额外机制 | 默认按代码或成交额展示，收益排序需用户主动点击；不得在首页露出；不得推送给用户 |
| 工时估算 | 6~8h + 合规复核 1h |
| 体积增量 | 约 2KB |
| 建议 | **需用户书面拍板**；不建议默认做 B |

### 产品建议

- 若目标是"满足好奇"，**A 足够**：用户能看到"多数标的历史上是什么水平"，且不产生买入指向；
- B 的价值是"可对比"，但代价是把站点推向"选股工具"叙事，与"条件单辅助计算、策略学习"的定位冲突；
- 若用户坚持 B，必须同时接受：入榜门槛、非默认排序、非首页露出、合规复核通过。

> **结论：本卡标"需用户拍板"。未拍板前 01_req 只定义 A 的开发范围；B 仅保留为备选方案，不排期。**

## 验收标准（粗，形态 A）

1. 概览卡展示 4 个统计量（正收益只数 / 收益中位数 / 胜率中位数 / 回撤中位数）与样本标的数；
2. 可选分档直方图，分档边界与文案固定；
3. 不出现任何标的代码或名称；
4. 明确标注"非推荐、历史表现不代表未来收益"与统计区间；
5. 393px 可用；
6. 数据来自预计算 JSON，不新增请求类型。

## 非目标

- ❌ 全市场排行（只统计 59 只池）；
- ❌ 每日 TOP 变化、榜单订阅/推送；
- ❌ 收益排行榜上首页；
- ❌ 在拍板前实现形态 B。

## 定位

- 让"回测"从单标的查询升级为"池内整体水平"的认知；
- 为后续是否做付费内容提供数据（用户是否关心"整体分布"）。

- 用户对 A/B 形态拍板；
