## 一句话描述

对外只上**中性分布概览**；把"按收益排序的 TOP10"放进**独立内测路由**，不对外发布。

## 背景

用户反馈：想看看"回测收益率 TOP"，"读者会好奇"。

用户已拍板（2026-11-04）：

1. **拆成两件**：中性分布对公众上线；TOP10 排序做成内测页，不对外发布；
2. **用户已接受内测页的合规责任**；
3. 本卡如实记录静态站的访问限制：**没有真正的私有访问**，`noindex` 只能降低被搜索引擎收录，**已知 URL 仍可直接访问**。

## 形态 A：中性分布（对外）

- 位置：回测页 `/tools/backtest` 结果区下方的「回测结果概览」区块（不新增公开路由）；
- 内容：正收益只数、收益中位数、胜率中位数、回撤中位数、样本数；可选 4 档分布条（只显示数量）；
- **不出现任何标的代码/名称**；
- 必需文案："以下为池内标的回测统计分布，非标的推荐" + "历史表现不代表未来收益" + 区间/样本数 + "未计佣金与滑点"。

## 形态 B：TOP10 内测页（不对外）

| 项 | 口径 |
|----|------|
| 路由 | `/labs/backtest-top`（独立、不与公开页面同层级） |
| 收录控制 | `<meta name="robots" content="noindex, nofollow">`；`robots.txt` 增加 `Disallow: /labs/` |
| 站内入口 | 不进导航、不进 sitemap、公开页面无任何链接；仅团队内部知道 URL |
| 页面标识 | 顶部固定横幅：`内测页 · 不对外发布 · 历史统计，不构成投资建议` |
| 内容 | Top10 表格：代码、名称、区间、收益率、胜率、笔数；入榜门槛平仓笔数 ≥ 5 |
| 排序 | 收益率降序（内测目的），但必须显示笔数与区间；不得出现"最佳/最强/推荐/热门" |
| 分享 | 无分享按钮、无二维码、无图片导出 |
| 已知限制 | **静态站无真正私有访问**：任何知道 URL 的人都能打开；本页仅靠"不链接 + noindex"降低曝光，不能阻止访问 |

## 验收标准（粗）

1. A 区块对外可访问，5 项统计与 JSON 一致，无标的代码/名称；
2. A 区块文案齐全（非推荐、历史表现不代表未来收益、区间/样本数、未计佣金与滑点）；
3. B 页可访问但带 `noindex,nofollow`；`robots.txt` 含 `Disallow: /labs/`；
4. B 页不在导航、不在 sitemap、公开页面无链接；
5. B 页顶部有"内测页·不对外发布"横幅；
6. B 页入榜标的笔数均 ≥ 5，数字与 JSON 一致；
7. 393px 可用，B 表在移动端转卡片列表；
8. 全站无 `推荐/热门/最佳/最强`。

## 非目标

- ❌ 真正的登录/鉴权/密码门（静态站不具备，且本期不引入服务端）；
- ❌ 全市场排行（只统计 59 只池）；
- ❌ 每日榜单变化、订阅、推送、分享海报；
- ❌ 把 B 链到首页或任何公开页面；
- ❌ 在公开页展示任何按收益排序的标的列表。
