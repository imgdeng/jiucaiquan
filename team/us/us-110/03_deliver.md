### 5.1 措辞裁决（不留灰区）

- **禁用词扫描应为绝对零命中，不设「免责声明块例外」。** 理由：`docs/compliance.md` 的默认免责声明原文本身不含任何禁用词，所谓「声明需要例外」的前提不成立；一旦开例外，就容易把「不构成推荐」写进页面，反而触发机械扫描。
- **「仅代表成交活跃度，不构成任何投资暗示」予以认可**：语义完全覆盖 D3「仅代表成交活跃度、不构成任何推荐或暗示」，且不含禁用词。**不得**改写成「不构成推荐」。
- **结论**：AC-7 该项通过；建议产品马在下一版需求里把「不构成推荐」统一改为「不构成推荐或暗示」的等价表述（需求侧文字，不由工程侧改）。

## 六、独立复算证据（P0-1）

3m 实际区间 `2026-08-04 ~ 2026-11-03`（60 个交易日）。同一数据层下，仅改变「第几日收盘结算」：

| 标的 | 现行 JSON（实为 4 日结算） | 按 §4 的 5 日结算 | 差异 |
|---|---|---|---|
| 510300 | 7 笔 / 0 胜 / 0.0% / -8.16% / 8.55% | 6 笔 / 0 胜 / 0.0% / -10.06% / 11.78% | 少 1 笔，累计 -1.90pp |
| 600519 | 8 笔 / 5 胜 / 62.5% / +8.68% / 2.89% | 7 笔 / 4 胜 / 57.1% / +4.26% / 6.43% | 胜率 -5.4pp，累计 -4.42pp |
| 300750 | 9 笔 / 0 胜 / 0.0% / -43.24% / 43.24% | 8 笔 / 0 胜 / 0.0% / -42.31% / 49.08% | 最大回撤 +5.84pp |

- **全池 60 只**：59 只指标发生变化；累计收益率偏差中位 **2.22pp**、最大 **23.64pp**（600487 亨通光电）；胜率最大偏差 30pp。
- **反证**：现行 60 份 JSON 在「4 日结算」下 **60/60 精确复现**（笔数、胜率、累计收益率、最大回撤逐项相等），说明不是随机误差，而是 [simulate_window](file:///Users/gdeng/work/jiucaiquan/services/market-data/build_backtest.py#L378-L396) 的 `exit_idx = i + hold - 1` 与 `range(i+1, i+hold)` 少算一天；而同函数上方的 `while i <= end_idx - hold` 与 `dates[i:i+hold+1]` 又按 5 日预留窗口，**实现内部自相矛盾**。
