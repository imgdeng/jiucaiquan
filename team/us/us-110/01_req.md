## 4. 回测口径（冻结，工程马不得自行变更）

> 指标口径一旦冻结，任何调整必须由产品马改本文件；工程马不得"顺手优化"口径。

### 4.1 策略规则：Pivot 条件单（次日低吸/高抛）

以信号日 D 的日线 OHLC（前复权）按现有 [calculateConditionOrder](file:///Users/gdeng/work/jiucaiquan/apps/web/src/lib/strategies/condition-order.ts#L43-L85) 计算：

- `base = (2*close + high + low)/4`，`range = high - low`；
- `buy = base - range`，`sell = base + range`（`rangeMultiplier = 1`，默认加权模式）。

交易日 D+1 起判定：

| 情形 | 处理 |
|------|------|
| D+1 最低价 ≤ `buy` | 以 `buy` 成交买入 |
| 买入当日最高价 ≥ `sell` | 当日以 `sell` 卖出，记 1 笔平仓（盈利） |
| 仅买入未卖出 | 继续持仓，逐日检查 `high ≥ sell` |
| 持有满 `holdDays = 5` 个交易日仍未达 `sell` | 按第 5 个交易日**收盘价**平仓（盈利或亏损均计入） |
| D+1 最低价 > `buy` | 该信号作废，**不计入交易笔数** |

执行约束：

- **串行单仓**：同一时间最多 1 笔持仓，平仓后才接受新的信号（避免虚构并发收益）；
- **不计佣金、滑点、冲击成本**，页面必须明示；
- 前复权价与 archive 快照一致，**不新建数据源**。

### 4.2 指标公式（可机械复算）

| 指标 | 定义 |
|------|------|
| 胜率 | 盈利平仓笔数 / 平仓总笔数（百分比，保留 1 位小数） |
| 单笔收益率 | `卖出价 / 买入价 - 1` |
| 累计收益率 | `Σ(单笔盈亏额) / 10000`（每笔名义投入 1 万元、等额、不复利，保留 2 位小数） |
| 最大回撤 | `max(1 - 权益_t / 峰值权益)`，权益按逐交易日"已实现盈亏 + 持仓浮动盈亏"计算（保留 2 位小数） |
| 交易笔数 | 平仓总笔数（未触发买入的信号不计） |
| 样本不足 | 平仓笔数 < 3 时，指标照常显示但必须附"样本不足（N 笔）"标注，不得隐藏样本数 |

## 5. 功能需求

### FR-1 页面与入口

- 新增页面路由 **`/tools/backtest`**，标题含"回测"与"历史表现"；
- **首页保留 1 个显式主 CTA**（Hero 回测按钮）；「今日工具台」卡片可直接点击进入对应工具；同一页面不得出现指向同一目标的两个同类 CTA（例如两个大按钮），卡片链接不计为第二个主 CTA；计算器页 `/tools/condition-order` 亦有中性入口链接（如"查看历史回测"）；
- 顶部导航是否新增「回测」由工程马决定，但不得破坏 AC-8（393px 不溢出）。

### FR-2 标的选择（固定池，非自由输入）

- 标的只能从**预计算标的池**中选择：搜索框按代码/名称过滤 + 列表点选（交互与计算器页 `select_quote` 同源体验）；
- 池规模：**≥ 50 只，其中 ETF ≥ 25、个股 ≥ 25**；取 `leaderboard.json` 末日成交额头部标的，并**剔除债券/货币类 ETF**（沿用 `build_leaderboard.py` 的 `BOND_KEYWORDS`）；
- **默认排序 = 末日成交额降序**（D3）。排序依据仅代表市场成交活跃度，**不构成任何推荐或暗示**；页面不得出现「热门」字样；
- 池内须包含 `510300`（沪深300ETF）与 `600519`（贵州茅台）**只要其实数据可用**；不可用则记录在 `02_eng.md` 说明；
- 搜索框输入池外代码：提示"暂未覆盖该标的（标的池共 N 只）"，**不发起计算**；
- 页面**不得出现**可输入任意代码并"开始回测"的入口（无自由标的参数）。

### FR-3 策略与区间选择（无自由参数）

- 策略：下拉/单选，**至少 1 项**：`Pivot 条件单（次日低吸/高抛，最长持有 5 个交易日）`；
- 区间：3 个预置档（`3m`/`6m`/`12m`）；**本迭代仅 `3m` 可选**，`6m`/`12m` 置灰「数据积累中」（D2）；
- **不得出现日期选择器**、不得出现"参数输入框"（倍数/持有天数等全部固定）。

### FR-4 结果摘要

结果卡必须同时展示以下 6 项：

1. 实际数据区间 `start ~ end`（含样本交易日数）；
2. **胜率**（百分比 + `wins/trades`）；
3. **累计收益率**（含"等额 1 万元/笔、未计佣金与滑点"注释）；
4. **最大回撤**；
5. 两行内说清策略规则（次日低吸买入、达高抛卖出、最长持有 5 日）；
6. 强制声明：`历史表现不代表未来收益`。

- 切换标的或切档**不产生额外网络请求**；首次选择某标的时按需加载该标的摘要（约 1KB），此后同标的切换走缓存；摘要须在 **≤ 500ms** 内更新；
- 无满足门槛的数据时，展示"该标的暂无足够数据"，不显示 0 值或伪造数字。

### FR-5 一键复制回测摘要

- 按钮"复制回测摘要"，文案模板（字段顺序固定）：

```
{name}({code}) 回测摘要 · {strategy} · {windowLabel}
区间：{start} ~ {end}（{tradingDays} 个交易日）
胜率：{winRate}（{wins}/{trades} 笔）
累计收益率：{cumReturn}（等额 1 万元/笔，未计佣金与滑点）
最大回撤：{maxDrawdown}
规则：次日跌至低吸价买入，达到高抛价卖出，最长持有 5 个交易日
历史表现不代表未来收益，仅供学习研究，不构成投资建议。
```

- 复制成功 → 按钮"已复制到剪贴板"（1.6s 复位）；失败 → 复用 us-105 的 fallback + "复制失败，请手动选中"提示，**不得静默**；
- 复制**不受任何限制**，页面不出现付费/订阅提示（承接 us-105：复制是漏斗终点，不能被挡）。

### FR-6 静态预计算产物

- 新增构建脚本（建议 `services/market-data/build_backtest.py`，只读 archive + 复用前复权逻辑，**不改 `build_leaderboard.py`**）；
- 产物写入 `apps/web/public/data/backtest/`：
  - 索引：标的池 + 可用档位 + 数据区间元信息（≤ 150KB，未压缩）；
  - 单标的摘要：每个标的 1 个文件（≤ 20KB），含各档位指标与样本数；
  - **不做明细产物**：逐笔交易与权益曲线本迭代不生成、不展示，整体移至 us-108 落地后（D1）；
- 构建需**幂等**：连续两次运行，除 `generatedAt` 外产物一致；
- 页面**零计算**：所有数字来自 JSON，前端只做展示与格式化。

### FR-7 埋点（新增事件）

| 事件 | 触发时机 | 必带字段 |
|------|---------|---------|

### FR-8 合规文案

- 页面显著位置（首屏结果区上下均可见）展示 `docs/compliance.md` 的默认免责声明全文；

- 允许 `买入`/`卖出`/`低吸`/`高抛`，但**仅作为策略规则说明**，不得写成祈使句（如"建议买入""现在可买"）；
- 标的列表**默认排序不得按收益率降序**；默认排序依据为**末日成交额**，页面须能看出该排序依据，且**不构成任何推荐或暗示**（D3）；

- 不做任何"哪只更值得买"的比较结论；
- 页面不出现明细区、订阅提示、价格或任何付费相关文案（D1）。

## 8. 非目标（本迭代明确不做）

- ❌ 自由参数回测（任意代码、任意起止日、任意倍数/持有天数）；
- ❌ 多策略（加权均价 / ATR / 布林带）——us-107 未落地，不虚挂；
- ❌ **付费墙整体**（占位卡、订阅提示、明细展示、价格、订单、收款码、会员体系、`paywall_view`/`paywall_click`）——**移至 us-108 落地后，不属本迭代范围**（D1）；
- ❌ 逐笔明细可视化、权益曲线绘制、CSV/图片导出、分享海报；
- ❌ 组合回测、多标的对比、仓位/资金管理、手续费滑点建模；
- ❌ 实时回测、盘中信号、定时刷新；
- ❌ 用户账号、自选同步、云端保存；
- ❌ 小程序端回测（类目与"零请求"约束，归 us-109 之外另行评估）；
- ❌ 新增数据库、常驻服务、第三方行情源或第三方回测框架。
