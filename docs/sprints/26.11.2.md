## 11-10 复测定稿（工程马，全部为线上真实请求）

### 事实

| # | 实测 | 结论 |
|---|------|------|
| 1 | `POST /api/track`（合法 `page_view`/`search`/`calculate`/`copy`）→ **204**，响应体 0 字节；随后 `GET /api/report` 回读，`2026-11-10` 当日行出现 `page_view`/`search`/`calculate`/`copy`，`topTerms` 出现探针词 | **写入成功并落库**。204 是 `onRequestPost` 的 noop 设计，写入在 `await env.DB.prepare(INSERT).run()` 之后返回 |
| 2 | `GET /api/report?key=<持有者>&format=json` → **200**，16 类事件、`daily` 最近一天 `2026-11-10`；不带 key 或错 key → **403** | **读取正常**；`403` 是 `report.ts` 的显式保护（无 key 配置时是 404），不是故障 |
| 3 | 7 日窗口（11-04~11-10）内 `search/calculate/copy` 探针前均为 **0**；30 日为 `search 18 / calculate 13 / copy 5`；同期 `backtest_view 9 / backtest_result 23` | 7 日内三段为 0 是**流量事实**（计算器无访问，流量在 `/tools/backtest/`），不是管道故障。验收口径"7 日内三段非零"测的是流量，**重定归项目马**，工程侧不改口径 |
| 4 | 带 `reason` 字段的事件仍 204 且落库 | 线上仍是旧版 `track.ts`（`fceeee8f6` 未上线），旧代码忽略未知字段，故当前无缺列风险 |

判定：上游 P0「`/api/track` 线上 403、D1 无新增数据、漏斗不可得」**不成立**；`track.ts` 不因该 P0 改返回码。

### 可观测性改动（本次）

- `onRequestPost` 的 `catch` 由"静默 204"改为 `console.error` + **500**；成功路径仍 204。
- 500 的可见位置：Cloudflare Pages 项目 → Functions 日志（`wrangler pages deployment tail` 或控制台实时日志）、以及 Pages 请求状态码统计。前端 `sendBeacon` 不读响应，故这是可观测性改动，不改变前端行为。
- 本地实测（`wrangler pages dev` + 本地 D1）：空库（无 `events` 表）→ **500** 且日志出现 `[track] 埋点写入失败 D1_ERROR: no such table: events: SQLITE_ERROR`；建表后同一请求 → **204** 且行数 +1。

### 上线顺序硬约束（`fceeee8f6`）

1. **先**在远端 D1 执行 `services/telemetry/migration_add_reason.sql`（`ALTER TABLE events ADD COLUMN reason TEXT;`），验证：`wrangler d1 execute jcq-telemetry --remote --command "PRAGMA table_info(events);"` 出现 `reason TEXT`。
2. **后**上线含 `reason` 的 `track.ts`。
3. 反序后果：每条 `INSERT` 都引用不存在的列 → SQLite 报错 → 异常被 `catch` 吞掉 → 返回 204，**所有事件（不只 `copy_fail`）静默丢失**，且外部看不出写入失败。

### 测试探针数据（需排除）

11-10 复测向线上 D1 写入 6 行探针事件，标识为 `sid='ffffffffffffffffffffffffffffffff'`、`term='probe-us116'`（`page_view` 3 行 + `search`/`calculate`/`copy` 各 1 行）。

- 工程侧无远端删除权限，**未清理**；周报与漏斗口径统计需排除这 6 行（当日 `page_view` 真实值为 3 行全部为探针）。
- 可执行 SQL（有权限者）：

```sql
DELETE FROM events WHERE sid = 'ffffffffffffffffffffffffffffffff';
```
